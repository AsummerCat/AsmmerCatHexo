#  2. 内网隧道代理端口转发 或者SMB
Netsh  win自带端口转发
```
windows系统自带命令行程序,攻击者无需上传第三方工具即可利用netsh程序可进行端口转发操作
可将内网中其他服务器的端口转发至本地访问运行这个工具需要管理员的权限

比如 102.168.111.128:8888 转发 192.168.52.138:3389

netsh interface portproxy add v4tov4 listenaddress=192.168.111.128 listenport=8888 connectport=3389    connectaddress=192.168.52.138

```
